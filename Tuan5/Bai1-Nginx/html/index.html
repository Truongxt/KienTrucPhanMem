🐳 Welcome to Nginx - Docker Compose

Chúc mừng! Container Nginx của bạn đang hoạt động!

Thông tin Container:

  • Host Port: 8080
  • Container Port: 80
  • Image: nginx:latest
  • Status: ✅ Running

Bạn có thể chỉnh sửa file HTML này (html/index.html) để tùy chỉnh nội dung.

Các lệnh hữu ích:

  • docker-compose ps - Xem các container
  • docker-compose logs -f - Xem logs
  • docker-compose down - Dừng container
